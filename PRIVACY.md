# PromptShelf Privacy Policy

PromptShelf is a local-first Chrome extension for browsing and copying Markdown prompt files from a folder you choose.

## Data Collection

PromptShelf does not collect, transmit, sell, rent, or share user data.

The extension does not send prompt files, prompt text, browsing history, clipboard contents, account information, or analytics data to any server.

## Local Storage

PromptShelf stores data locally in your browser so the extension can work between popup sessions. This may include:

- The selected agent setting.
- The last selected folder label.
- A local cached copy of parsed prompt metadata and prompt text.
- A browser-held folder handle for the folder you selected.

This data stays on your device. It is not uploaded by PromptShelf.

## Clipboard

PromptShelf writes to the clipboard only when you click the Copy button. PromptShelf does not read clipboard contents.

## Local Files

PromptShelf reads Markdown files only from a folder you explicitly choose. If you use the edit feature, PromptShelf writes changes back only to the selected prompt file after you click Done.

Do not store passwords, API keys, tokens, or private credentials in prompt files.
